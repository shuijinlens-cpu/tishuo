# 题说 Tishuo · 拍照生成讲题视频

拍照上传一道题 → AI 识题 → 自动生成分镜讲解动画 + 人声配音 → 一键导出视频（可直发抖音 / 视频号 / 班级群）。

覆盖 **小学 / 初中 / 高中 / 大学** 四个学段，每个学段有专属讲解引擎；还支持**定制讲解**：你写下讲解思路，AI 严格按你的顺序生成。

**在线使用**：https://shuijinlens-cpu.github.io/tishuo/
**手机安装**：https://shuijinlens-cpu.github.io/tishuo/download.html （安卓 APK / iPhone 添加到主屏幕，同一个永久链接）

---

## 为什么不是"文生视频"？

直接用 Sora / 可灵这类视频大模型讲数学，公式几乎必错、数字会跳变，不可用。

题说的思路是 **AI 只负责"解题 + 写分镜"，画面由程序精确渲染**：

```
拍照/粘贴题目
   ↓  视觉大模型（可选）
题目文本
   ↓  文本大模型 → 输出"分镜 JSON"（每屏：画面类型 + 数学对象 + 解说词）
分镜 JSON
   ↓  本地 Canvas 渲染引擎（逐屏动画，数学 100% 精确）
   ↓  TTS 配音（可选）
   ↓  MediaRecorder 逐帧录制 + 音轨合成
讲解视频（WebM）
```

好处：**数学不会画错**、可预览可逐屏修改、渲染全部在浏览器本地完成、成本只有文生视频的几十分之一。

## 学段讲解引擎

| 学段 | 风格 | 侧重画面 |
|---|---|---|
| 🧸 小学 | 趣味、拟人、生活场景 | 实物模型（🍎🐰）、饼图/分割条、大字号、口诀 |
| 📐 初中 | 数形结合 | 代数→函数图像/数轴；几何→辅助线生长、旋转/翻折动画 |
| 🧭 高中 | 秒杀技巧 + 图形推演 | 对称轴、切线、区域面积；几何动态建系 |
| 🎓 大学 | 克制、板书感 | 原理 → 推导 → 标准步骤，不做花哨动画 |

## 功能

- **拍照 / 截图 / 粘贴**上传题目（Ctrl+V 直贴），相机拍摄，图片本地压缩
- **AI 识题**：视觉模型把图转写成文本
- **AI 生成讲解**：自动解题 + 设计 4~7 屏分镜
- **定制讲解**：输入你的讲解思路（如"先讲为什么，再推公式，最后给口诀"），AI 严格按顺序编排
- **分镜编辑器**：每屏的标题/公式/解说词/时长都可改，改完立即生效
- **实时预览**：Canvas 动画 + 浏览器配音（免费）或接口配音（可录进视频）
- **一键导出**：30fps 逐帧录制，横屏 16:9 / 竖屏 9:16（抖音）两种画幅，可存封面图
- **演示模式**：不配任何 Key 也能用 8 道内置样题体验全流程

## 拍照识题：识别 → 确认 → 修改 → 生成

这一版把「识题」做成了真正可用的闭环：

1. **拍照**（手机调系统相机，电脑可拖拽 / Ctrl+V 粘贴）
2. **本机识别**：内置 tesseract.js 中文 OCR（约 2MB 模型 + wasm 随应用分发，**不走 CDN、不联网也能用**）；
   配了视觉大模型时自动改用大模型识题，公式和图形题更准
3. **确认卡**：显示原图缩略图、置信度、识别文本，**文字可直接改**——识别错了当场修，不用重新拍
4. **生成**：确认无误后一键出分镜视频

即使**完全不配 Key**，下面这些题型也能本机直接生成讲解（含图像动画）：
一元一次方程、一元二次方程（带抛物线交点图）、四则与分数运算。
更复杂的题目引导你开通免费大模型（智谱 `glm-4-flash` / `glm-4v-flash` 免费）。

## 人声：为什么现在不像机器了

三层改造：

| 层次 | 做法 |
| --- | --- |
| 音色 | 内置 6 种音色预设（温柔女老师 / 磁性男老师 / 活泼少女 / 故事叔叔 / 播音 / 自定义），按学段自动推荐；优先挑设备上的**神经语音**（名称含 Natural / Online / Neural，如晓晓、云希），自动避开 eSpeak 这类机器人音 |
| 韵律 | 按标点切成"呼吸单位"，句号停 0.34s、逗号 0.16s，问句升调、列举放慢；不再一口气念完整段，也不会被 Chrome 的长文本 bug 截断 |
| 云端人声 | 接 `qwen-tts / cosyvoice`（阿里百炼）或 `gpt-4o-mini-tts`（OpenAI），支持用一句话描述声音风格（"温柔耐心的女老师，关键步骤语气加重"），还支持音色复刻 |

> 注意：系统音色免费随点随听，但浏览器不允许抓取系统语音的输出流，所以**要导出带人声的视频必须用云端人声**。设置里可以一键试听对比。

## 手机 App

- **安卓**：GitHub Actions 自动用 Capacitor 打包 APK，发布到站点同域名的 `tishuo.apk`（**国内可直接下载**，不依赖 github.com），同时在 Releases 留一份永久链接
- **iPhone**：Safari 打开 → 分享 → 添加到主屏幕（PWA，全屏无地址栏，识题模型缓存后可离线）
- 原生壳里拍照走系统相机（@capacitor/camera），比网页版稳

## 快速开始

```bash
npm install
npm run dev        # http://localhost:5173
npm run build      # 产物在 dist/
```

打开页面后：选学段 → 点一个示例（或拍照/输入题目）→ 生成讲解 → 播放 → 导出视频。

2. 仓库 **Settings → Pages → Source 选 "GitHub Actions"**

## 接入 AI（可选，但强烈推荐）

不配置 = 演示模式（内置样题）。配置后解锁真实识题与按题生成。

在网页右上角 **⚙ 设置** 里填：

| 服务商 | 接口地址 | 文本/视觉模型 | 配音 |
|---|---|---|---|
| 阿里云百炼（通义） | `https://dashscope.aliyuncs.com/compatible-mode/v1` | qwen-plus / qwen-vl-max | qwen-tts |
| 火山方舟（豆包） | `https://ark.cn-beijing.volces.com/api/v3` | doubao-1.5-pro / doubao-1.5-vision-pro | 需另配 |
| 智谱 GLM | `https://open.bigmodel.cn/api/paas/v4` | glm-4-plus / glm-4v-plus | 需另配 |
| OpenAI | `https://api.openai.com/v1` | gpt-4o-mini / gpt-4o | gpt-4o-mini-tts |

- Key 只存在**你本机的 localStorage**，不经过任何第三方服务器
- 遇到浏览器跨域（CORS）限制，或想把 Key 藏到服务端：用 [`proxy/worker.js`](proxy/worker.js) 部署一个免费的 Cloudflare Worker（文件头有 4 步部署说明），然后把接口地址指向 Worker 即可
- **配音**：浏览器配音免费但录不进视频（导出的是字幕版）；要"带人声成片"请在设置里选"接口配音"并点"合成配音"

## 定制讲解怎么用

左侧切到 **定制讲解** 标签，写下你的思路，例如：

> 先讲为什么要配方（用图像看对称性），再推顶点式，最后给一个"看到 a>0 就找最低点"的秒杀口诀。

生成时会严格遵守你写的**顺序和重点**，不增删步骤。配合"拍照讲题"里识别好的题目一起用效果最好。

## 导出说明

- 格式 WebM（VP9/Opus），抖音、视频号、B 站、微信均可直接上传；如需 MP4 用任意转码工具（如 `ffmpeg -i in.webm out.mp4`）即可
- 录制是**实时逐帧**的：60 秒的讲解需要约 60 秒录制时间，期间别切走标签页
- 分辨率 1280×720（横屏）/ 720×1280（竖屏）

## 扩展点（面向未来模型）

- **换/加模型**：全部走 `src/lib/ai.ts` 的 OpenAI 兼容适配层，界面里改配置即可，不用改代码
- **新增画面类型**：在 `src/engine/render.ts` 的 `renderScene` 里加一个 `case`，并在 `src/lib/ai.ts` 的 `SCHEMA_DOC` 里告诉模型怎么用 —— 例如以后想接文生视频模型做"片头实景"，可以加一个 `broll` 场景类型，把生成的视频片段嵌入时间线
- **离线渲染脚本**：`scripts/preview.ts` 可把分镜批量渲染成 PNG（CI 校验排版用）

